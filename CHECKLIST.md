# Prep checklist

Stage 4. Start only after the critic (`prompts/slide-critic.md`) has
returned **READY**. The critic covers the evidence, the deck, privacy,
and the rigor bar, so they aren't repeated here.

## T-30 days: refresh (stage 1, refresh mode)
- [ ] Run `prompts/research-agent.md` in **refresh mode** on the
      session's claim matrix. Every tool-behavior claim is re-verified,
      and anything stale is replaced or cut.
- [ ] Rebuild (`scripts/build.sh`) and run the critic again. Still
      READY?

## T-7 days
- [ ] The intake's platform facts have been re-checked and dated (plan
      type, memory default, features the demos depend on).
- [ ] Outputs built and **opened**: the editable .pptx (speaker notes
      present), the deck PDF, the Peer Leader Guide, and the artifact.
- [ ] Both co-leaders have read the Peer Leader Guide and agreed on the
      A/B roles.
- [ ] Printing sent: handouts, cards, leader-only answer key.
- [ ] The run sheet still adds up to exactly 50 minutes after any
      edits.

## T-1 day
- [ ] **Re-run every failure prompt on the students' plan.** Failure
      demos decay (T-23). Record the date, the result, and whether it
      still fails.
- [ ] **Capture a backup screenshot** of each failure, **redact it**
      (crop out the account name, sidebar chat titles, and the memory
      panel), and name the file in the speaker notes (H-02).
- [ ] If a failure no longer reproduces, switch to the prepared
      polished-output trap. Don't wing it.
- [ ] Full timed rehearsal with both co-leaders. Note any segment that
      runs over.
- [ ] Copy the outputs into `Session N Materials` (they're already
      named for it).

## T-1 hour
- [ ] Demo machine logged in, chat history clear of unrelated or private
      chats, memory setting confirmed.
- [ ] Deck open in presenter view, with speaker notes visible to the
      presenter.
- [ ] Backup screenshots reachable offline.
- [ ] Timer ready (co-leader B). Printouts counted. Exit-ticket slips
      ready, if used.
- [ ] Wi-Fi checked; hotspot as a fallback.

## After teaching (stage 5)
- [ ] Retro (`lessons/retro-template.md`) within 48 hours: counts and
      paraphrases only, no names.
- [ ] Update the claim-matrix rows the retro flagged.
- [ ] Add students' unanswered questions to the next research run.
