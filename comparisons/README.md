# comparisons/

Claim matrices: one row per claim, recording which sources agree or
disagree, who ran each source, its date, how confident we are, and
whether the claim is teachable. Format and rules:
`docs/research-method.md`.

| File pattern | Paired with |
|---|---|
| `[topic]-matrix.md` | `research/[topic]-brief.md` |

ID prefixes: `C-` content claims (per lesson topic), `T-` teaching
methods, `H-` house rules (rules with no source, labeled as such).

Lessons, decks, and artifacts cite these IDs. If a claim is not in a
matrix, it is not in a lesson.
